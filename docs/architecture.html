Architecture

A control plane that cannot lie, and a data plane that cannot run loose.

Every injection flows through one choke point — the Safety Governor — and every result is signed into an append-only ledger. Here is how the pieces fit, the seven-step loop, and the ten gates in full.

System overview

Control plane, data plane, signals.

The control plane decides and records. The data plane acts — but only on a signed decision. Signals come back from independent sources, and a correlation UUID threads the whole run together.

Components

What each piece is responsible for.

Catalog

The registry of experiments. Each one declares a hypothesis, steady-state probe, the ladder it asserts, SLOs, and framework mappings — as structured data, never executable payloads.

Safety Governor

The single choke point. It evaluates all ten gates and returns a signed decision. No code path dispatches a detonator without Decision{Allowed:true} — enforced by code and by test.

Verification Engine

Correlates signals to the injection by UUID and grades each rung of the response ladder against its SLO: within SLO, slow, failed, or inconclusive.

Scoring

Rolls verdicts into a weighted per-service efficacy score. Prevention counts most; an expected-but-untested family scores 0.0. The scorecard never flatters.

Evidence Vault

An append-only, Ed25519-signed ledger of every decision, approval, detonation and verdict — tamper-, reorder- and truncation-evident, and verifiable offline.

Agent & Detonators · Signal sources

The agent executes a single declared, reversible condition against the target; independent sources — metrics, logs, the alert bus, the pager — report back for verification.

The loop · in detail

Seven steps, every run, no exceptions.

HYPOTHESIZE

Load an experiment from the catalog: its steady-state definition, the adversarial condition, the ladder rungs it asserts, and the SLO for each. A correlation UUID is minted for the run.

GATE

The Safety Governor evaluates all ten gates and proves the system is in steady state. Any refusal denies the run; every reason is recorded. This is the only path to injection.

ARM

A capability credential is minted for exactly this run — narrowly scoped, time-boxed, signed, and auto-expiring. No credential ever outlives its run, and the platform cannot widen its own scope.

DETONATE

The agent injects one pre-declared, bounded, reversible condition against the target — stamped with the correlation UUID so it can never be confused with a real incident.

OBSERVE

Independent signal sources are polled across the ladder — prevented, detected, alerted, paged, ticketed — and matched to the run by UUID, never by timing coincidence.

REVERT

The condition is undone and the revert is independently verified. If an action could not be reverted and the revert checked, the Governor would never have allowed it in the first place.

ADJUDICATE

Each asserted rung is graded against its SLO and the verdict computed — PASS, FAIL_OPEN, or INCONCLUSIVE, never fudged. A signed receipt is written and the scorecard updated.

The Safety Governor

Ten gates. All evaluated. Never short-circuited.

A single refusal denies the run — but every gate is still evaluated, so the full set of reasons is recorded in the ledger. This is the canonical evaluation order.

KILLSWITCH

The global kill switch must be disengaged. One switch halts all injection, everywhere, instantly.

SEV_ACTIVE

No active incident may be open for the target's team. Never pile chaos onto a live fire.

BLACKOUT

The current time must fall outside every declared change-freeze / blackout window.

PROMOTION

The experiment must have PASSed in every lower environment within the freshness window. Production is earned, not assumed.

CAPABILITY

The run must carry the exact capability it declares — a narrowly-scoped, time-boxed, signed grant that expires on its own.

APPROVAL

Required approvals must be present; production demands two humans from two distinct teams.

BUDGET

The blast radius — duration, traffic percentage, pod count — must fit the pre-set envelope for that environment and tier.

FAULT_DOMAIN

The target must share no fault domain with any in-flight run. No overlapping blast zones.

CONCURRENCY

A concurrency slot must be free. The platform caps how much can be in flight at once.

STEADY_STATE

The system must be provably in steady state right now, via a configured probe. No steady state, no detonation.

Fail closed and honest. Production injection is off by default and requires an explicit, signed, time-boxed capability grant plus two-person approval. Alert suppression is capped at 30 minutes and is schema-forbidden from ever covering an alert rule the experiment asserts on.
